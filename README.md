# Project 1: Data Cleaning & Preparation (DecodeLabs)

Cleaned an e-commerce orders dataset (1,200 rows, 14 columns).

- Missing values: 309 blank CouponCode cells (customer used no coupon), filled with NO_COUPON
- Duplicates: checked on OrderID, 0 found
- Formats: dates set to YYYY-MM-DD, text trimmed and standardised, prices to 2 decimals
- Verification: 0 duplicate IDs, 0 incorrectly formatted dates, 0 nulls

Files: cleaned_dataset.csv, clean_data.py, Change_Log_Project1.pdf, original dataset.
